# CLAUDE.md

Read and follow `AGENTS.md` first; it is authoritative. This file only adds
Claude Code specifics.

- Cloud sessions cannot reach the owner's Mac. When work needs macOS/Metal/the
  MuJoCo viewer, add or update a task in `docs/handoffs/MAC_LOCAL_HANDOFF.md`
  and continue with other cloud tasks.
- In a **local Mac session**, start with `docs/handoffs/MAC_LOCAL_HANDOFF.md`:
  run the pending tasks in order and write results back there.
- Owner-facing reports are in Turkish; keep them short and state which
  environment (cloud / GitHub macOS runner / owner's Mac / hardware) produced
  each result.
- Do not include model identifiers in commits, PRs, or files.
