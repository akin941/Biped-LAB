# biped_ds3218 learns to walk with DS3218MG servos and commanded-only feedback, M5 (MAC-47, WP4-40)

```
env: mac-m5 (macOS 27.0.1 arm64, 10 CPU, Python 3.12.13, MuJoCo 3.10.0, torch 2.9.1), 2026-11-23
revision: 53c919f (main), git_dirty false
run A: --robot biped_v1 --model biped_ds3218 --joint-feedback commanded --dr --envs 256 --seed 0 --track-yaw-std2 0.25
       --symmetry loss --mirror-loss-coeff 0.5 --torque-limit 1.96 --motor-no-load-speed 7.0, --iters 1500 --workers 8,
       --resume mac37-b/model_5000.pt; 3079 s
eval: eval_biped --dr --robustness (8 envs × 20 s) and --obs-mode runtime (16 envs × 20 s), same model / feedback / servo
```

## Training
Falls per iteration started at 4.07 (150-iteration mean), which is expected for a robot twice as heavy whose joint inputs now
mean the commanded targets. They dropped to 0.17 and stayed at 0.00–0.03 from iteration 300. Reward/step rose 0.092 → 0.126.

## Verdict
**WP4-40 met by run A. Run B was not needed.** The policy walks the 1.04 kg DS3218MG build using only the targets it sent. There are no falls,
vx ≥ 86 % of the command, and every joint's worst walking torque is ≤ 1.13 N·m (bar 1.3). Speed is the tighter margin: hip pitch and knee
run at p95 ~5.1 rad/s against 7.0 rad/s no-load, so torque at speed is worth checking on the bench once the servos are identified
(the model's gains and friction are guesses until then). No hardware was powered.
