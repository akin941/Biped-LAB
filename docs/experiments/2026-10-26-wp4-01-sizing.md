# WP4-01: sizing of biped_v1 (mass, CoM, joint loads, power, battery)

**Environment:** cloud (container) for the static analysis; gha-linux (CI job
`pretrained-policy`) for everything that uses Microduck walking telemetry. Not run on
the Mac. Simulation only: no hardware number is claimed.

## Method
- **Static loads** (`bipedlab.design.sizing.static_loads`): exact static inverse
  dynamics on the MJCF. With the robot still, `tau = g(q) - J^T W`; the base rows fix
  the ground wrench `W` (unique for one stance foot, minimum-norm for two). It also
  returns the centre of pressure (CoP) under each foot.
- **Single support at the stand pose** is the design case: all weight on one foot
  with the CoM still on the sagittal plane. Its CoP sits half the hip spacing inside
  the foot, so the hip roll holds weight × 40 mm. A real gait leans the body over
  the stance foot first, so this is an upper bound for hip roll.
- **Dynamic factor from simulation**: Microduck's official walking policy
  (`alpha_walking`, BAM actuator, 0.4 m/s command, 12 s, first 2 s skipped) is recorded
  in CI. Per joint type, its walking peak torque divided by Microduck's own static
  single-support torque is applied to our static torque (knee 1.0 rad). Joint types
  without a static load (hip yaw) use Microduck's walking peak scaled by mass × leg
  length. Speeds are scaled at equal Froude number (√(L_duck / L_ours)).
- **Requirement** = estimated walking peak × 2 (G4.1 margin), compared with the
  placeholder servo (0.52 N·m, 10 rad/s, XL330 class).
- **Power**: Microduck's mechanical power scaled by m·√L; electrical = mechanical /
  0.25 (small geared DC servo) + 2.5 W idle (computer, IMU, servo controllers);
  battery 2S 500 mAh, 80 % usable. These efficiency and idle values are
  assumptions to replace with datasheets in WP4-03.
- **Thermal**: RMS torque / stall torque per joint type; above 0.3 is flagged for a
  thermal check (rule of thumb, no motor model yet).

Telemetry samples torque once per 20 ms control step, so very short peaks inside a
step are not seen.
